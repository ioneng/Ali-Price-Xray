Ali-Price-Xray Settings

AI-assisted matching

Xray keeps using its local matcher first. Gemini is only asked to resolve ambiguous product-option matches.

Remembered keys are stored in browser extension storage, which is not encrypted. Leave this off to keep the key only for the current browser session.

Privacy

When Gemini assistance is enabled, Xray sends the selected reference option labels and a small shortlist of ambiguous candidate option labels to Google. If text alone remains unresolved, Xray may also send the public image URLs for those reference and candidate SKU thumbnails so Gemini can compare them visually. It does not send AliExpress cookies, account details, shipping information, prices, full page HTML, or browsing history.

Google states that Gemini API free-tier submitted content may be used to improve Google products.
